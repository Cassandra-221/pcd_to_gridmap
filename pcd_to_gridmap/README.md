这是一个将3D点云（PCD格式）转换为2D栅格地图的工具，主要功能是将3D点云投影到XOZ平面，生成可用于机器人导航的二维占据栅格地图。

使用通过优化算法判断点云图的地面范围：
RANSAC、MSAC 与 MLESAC 均为随机采样一致性框架下的鲁棒参数估计算法，三者通过随机采样与模型验证的方式从含有大量离群点的数据中提取正确模型。
RANSAC 采用硬阈值内点计数作为评价指标，仅统计误差小于给定阈值的点数，实现简单、计算速度最快，但对阈值选择极为敏感，且无法区分不同噪声水平的模型，适用于离群点比例较低、对实时性要求较高的场景。
MSAC（M-estimator SAC）在 RANSAC 基础上引入截断的误差平方和作为损失函数，将每个点的贡献由简单的计数改为误差平方，但超过阈值后截断为常数，从而获得更平滑的模型评估，降低了对阈值的敏感性，结果比 RANSAC 更加稳定，是兼顾速度与精度的折中方案。
MLESAC（Maximum Likelihood SAC）则将内点与外点建模为混合分布（内点误差服从高斯分布，外点服从均匀分布），通过最大化数据的似然概率来选择最优模型，能自动权衡内点与外点的分布特性，在噪声较大、离群点比例高或数据分布复杂时表现最为鲁棒，但计算量相对较大。

优先选择 RANSAC：当数据离群点比例较低（< 30%），且计算资源有限，需要快速得到一个粗略模型时。RANSAC 实现简单，速度最快，是大多数场景的默认选择。
优先选择 MSAC：当您希望获得比 RANSAC 更平滑的模型，同时又不希望增加过多计算量时。MSAC 在 RANSAC 基础上改进，对阈值不那么敏感，结果更稳定，是兼顾速度与精度的折中选择。
优先选择 MLESAC：当数据噪声较大、离群点比例高（> 50%），或者存在多个结构时，MLESAC 通过最大似然估计能获得更准确的模型。虽然计算量稍大，但在复杂环境下表现最佳。

主要功能：
1,点云投影：将3D点云投影到XOZ平面（X-Z平面）
2,高度过滤：可设置Y轴范围，只处理特定高度范围内的点
3,栅格化：将投影后的点转换为2D栅格地图
4,占据判断：基于点云密度判断栅格是否被占据
5,文件输出：生成PGM图像和YAML配置文件

命令行参数：
-r      <值>	分辨率（米/像素）
-s      <值>	地面检测算法：1(RANSAC方法);2(MLESAC方法);3(MSAC)三选一
-g    <值>      地面检测距离阈值 (米)
-min <值>	最小Y轴值（垂直方向）
-max <值>	最大Y轴值（垂直方向）
-o      <值>      障碍物判定阈值比例 [0,1]
-h,    --help	显示帮助信息

使用方法：
# 1. 基本用法：使用默认参数
./build/pcd_to_gridmap slam_cloud.pcd
# 2. 设置栅格分辨率（0.1米/像素）
./build/pcd_to_gridmap slam_cloud.pcd -r 0.1
# 3. 设置MLESAC方法进行地面检测
./build/pcd_to_gridmap slam_cloud.pcd -s 2
# 4. 设置垂直范围（只处理Y轴-0.5到0.5米之间的点）
./build/pcd_to_gridmap slam_cloud.pcd -min -0.5 --max 0.5
# 5. 显示帮助信息
./build/pcd_to_gridmap -h
